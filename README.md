# 26-Day Python Study Plan

Interactive study sheet for the **CodeWithHarry beginner Python course**, then 7 days beyond the video (Git, testing, APIs, algorithms).

Progress (checks, notes, bug log) is saved in **your browser** only.

## Open it (easiest)

1. Go to the repo on GitHub.
2. **Settings → Pages**.
3. Source: **Deploy from a branch** → branch `main` → folder `/ (root)` → Save.
4. After a minute, open the Pages URL shown there (usually `https://hossain2509013.github.io/python-26-day-study-plan/`).

No install. No terminal.

## Run locally

```bash
# any static server, e.g.:
npx serve .
# or open index.html in a browser (some browsers restrict localStorage on file://)
```

## How to use

1. Open the home page → pick a day.
2. Tick warm-up, practice, quests, and challenge items as you finish them.
3. Write notes, one bug, and one win at the bottom.
4. Progress stays on that device/browser.

## Course video

Days 1–18 use [CodeWithHarry — Python Tutorial for Beginners](https://www.youtube.com/watch?v=UrsmFxEIp5k).
